# Reference Library Index (read this first)

Three books, converted to Markdown with code, tables and headings preserved. Only chapters relevant to CSE110 are included.

## How to use it (for AI tutors)
1. Find the lesson's topic in the table below.
2. Read the **course cut** first. It holds exactly the pages/sections your teachers mapped, so it is small and exam-focused.
3. If the explanation needs more depth, open the **chapter file** for that topic. Each topic row lists the page window, and `SECTIONS.md` lists every section with its page.
4. Cite printed book pages (`<!-- CR p.40 -->` markers). PDF page = printed page + offset (CR +35, HF +38, Liang +23).
5. Never load a whole book. One chapter file at a time.

## What each book is best for
| Book | Use it for |
|---|---|
| Head First (HF) | First contact: intuition, analogies, "why", plus exercises with answers at the back |
| Liang (LI) | Worked examples, tracing tables, Check Point questions, programming exercises. Closest to the course |
| Complete Reference (CR) | The exact rule, exact terminology, tables of ranges and precise definitions |
