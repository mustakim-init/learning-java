### 1. The Kitchen Robot (What is Programming?)
Computers are not smart; they are just **very obedient and very fast**.
Think of a computer as a fast kitchen robot:
- It can chop 10,000 carrots a second.
- But if you say *"make lunch"*, it does nothing because it doesn't know what lunch is.
- You must tell it:
  1. Pick up knife.
  2. Take carrot from counter.
  3. Slice carrot.

**Programming** is simply writing down this exact step-by-step recipe.

---

### 2. Why Flowcharts?
Before writing code in a programming language like Java, programmers draw a **Flowchart**.
- A flowchart uses simple shapes connected by arrows.
- It prevents you from getting stuck before you write a single line of code.

---

### 3. The 4 Essential Shapes

| Shape | Name | Meaning | Real-world example |
|---|---|---|---|
| 🟢 **Oval** | **Start / End** | Turns robot ON or OFF | Start making tea / Finished tea |
| 🟣 **Rectangle** | **Process** | An action to perform | "Boil water", "Add sugar" |
| 🟡 **Diamond** | **Decision** | A Yes/No question | "Is water boiling?", "Want sugar?" |
| 🔷 **Parallelogram** | **Input / Output** | Getting data in or showing data out | "Enter user age", "Print result" |
| ➡️ **Arrow** | **Flow Line** | Shows which way to go next | Points to the next step |
